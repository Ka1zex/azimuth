# Azimuth Wiki

Откройте index.html в браузере после распаковки ZIP. Сборка не требуется.
Интернет нужен для BOOTSTRA.386 и внешних ссылок. Данные, медиа и скрипты локальные; поиск работает через file://.

## Состав
- index.html — главная, центральная колонка 90ch, лента и правая панель.
- articles.html — поиск и фильтр по 19 статьям.
- articles/ — отдельные HTML-статьи; 14 планов секторов, стартовый гайд, турели, проверка схем и картоделие.
- schematics.html — вход в библиотеку схем (проверенных .msch пока нет).
- media.html — поиск и постраничный просмотр 1032 медиафайлов.
- media-index.html — полный указатель без JavaScript.
- templates/ — 6 шаблонов в HTML и Markdown.
- about.html — источники, авторы, версия и статусы достоверности.
- assets/layout.css — разрешённые правки над BOOTSTRA.386.

## Правка контента
Редактируйте HTML непосредственно. Чтобы добавить статью, скопируйте templates/*.html в articles/, заполните поля, добавьте карточку в articles.html и обновите счётчик на главной. Общие стили и скрипты лежат в assets/.
Шаблоны Markdown предназначены для авторов; сайт не преобразует их автоматически.
Медиакаталог: assets/media-data.js; каждый объект хранит path, name, original, type.

## Оформление
Внешний CSS только BOOTSTRA.386. CDN-ссылка исправлена: BOOTSTRA.386@master вместо BOOTSTRA.386master (исходный URL возвращает 404).
Компоновка и hover реконструированы по предоставленным CSS. Исходного HTML/скриншота нет, поэтому пиксельное совпадение не подтверждено. Дополнительные CSS-правки разрешены пользователем.
Мобильная версия отключает масштабирование, складывает колонки и меню; prefers-reduced-motion также отключает масштабирование.
